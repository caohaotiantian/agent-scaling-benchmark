一分钟了解

让大模型直接编题，会稳定产出送分题——基线集合中 75.2% 的用例所有配置都能解出。 三次独立干预实验证明，无论输入什么，生成器都输出同一种难度。

本项目改为反向构造：从真实会话中重放出文件被修改前与修改后的两个版本， 以前者为待修复代码、后者为参考解，模型只负责编写能区分两版的测试。 缺陷来自真人真错，模型无法把任务改简单。
