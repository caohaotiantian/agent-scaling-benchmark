一分钟了解

让大模型直接编题，会稳定产出送分题——基线集合中 75.2% 的用例所有配置都能解出。 三次独立干预实验证明，无论输入什么，生成器都输出同一种难度。

本项目改为反向构造：从真实会话中重放出文件被修改前与修改后的两个版本， 以前者为待修复代码、后者为参考解，模型只负责编写能区分两版的测试。 缺陷来自真人真错。模型不能把缺陷改简单，但可以写出 grep 源码的测试绕开门禁——当前 31 条里 12 条如此，见参考资料 §3。

中档 74.2%（95% 区间 [56.8%, 86.3%]）——但这个数测于 2026-08-09 之前的有缺陷 harness，暂不可作为结论。 完整数据、置信区间与已知边界见项目介绍。

⚠️ 难度分布正在重测（2026-08-09）。 模型消融查出三个 agent 适配器缺陷， 其中两个位于 tool_loop —— 所有校准面板的最强锚点。 同一批用例、同一模型，仅修 harness 就使 GLM-5.2 从 25.8% 升到 83.9%。 本页与「项目介绍」中 2026-08-09 之前的难度数字暂不可作为结论， 见项目介绍 · 第 6 节。
